## 🚀 Featured Projects

### 1. Annotation Wizard — AI-Assisted Dataset Annotation

A web-based annotation service that uses object detection to generate YOLO-format labels from image datasets, with support for human review and correction.

- 📦 Upload image datasets as ZIP archives and generate annotations using YOLO inference through ONNX Runtime.
- 🏷️ Support for four road damage classes: D00, D10, D20, and D40.
- ✏️ Review and edit bounding boxes and class labels before exporting annotations.
- 🔐 API-key-protected endpoints and PostgreSQL-backed job persistence.
- 🐳 Docker Compose support for local development.

**Tech:** FastAPI, ONNX Runtime, PostgreSQL, Docker, REST APIs

- 🗄️ Uses PostgreSQL and SQLAlchemy for data persistence.
- 🔄 Manages database schema changes with Alembic migrations.
- 🐳 Containerized development environment using Docker Compose.
